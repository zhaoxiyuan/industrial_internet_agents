# 文档索引

## 阅读约定

- “标准接口”表示其他模块可以稳定依赖的入口；以下划线开头的函数均视为内部实现。
- `job_id` 是全流程作业标识；`task_id` 是阶段业务对象标识。跨阶段传递时不得互相猜测或静默替换。
- 文档中的 JSON 示例只展示稳定字段。新增兼容字段可以向后扩展，修改或删除既有字段需要同步更新调用方和文档。
- 文档与代码不一致时，以当前实现为准，并应在同一次修改中修正文档。
