## 3. `A7/prompt/` — 业务规则提示词（加载 / 修改 / 恢复默认）

> **设计原则**：业务规则的"出厂默认版"以 **Python 常量** 内嵌进 `.py`，避免依赖任何外部 `.md` 文件存在性；用户可调用函数 `save_rules()` **运行时覆盖**自定义版本（落到磁盘 `overrides/`），也可一键 `reset_rules()` 恢复默认。

### 3.1 目录结构

```
A7/prompt/
├── __init__.py
├── p8_prompt.py              # 唯一文件：默认常量 + 4 函数 + 单例 getter
└── overrides/                # 运行时生成（git 忽略）
    └── P8_RULES.user.md      # 业务用户通过 save_rules() 写入的自定义版
```

### 3.2 `A7/prompt/p8_prompt.py`（核心文件）

**职责**：

1. **默认版持久化** — 用 `P8_RULES_DEFAULT` 三引号常量作为 source of truth；不依赖任何 `.md` 文件存在性
2. **加载** — 优先读 `overrides/P8_RULES.user.md`，不存在则用默认常量
3. **修改** — 业务人员调用 `save_rules(content)` 写到 `overrides/`（不污染默认常量）
4. **恢复默认** — 调用 `reset_rules()` 删除 override 文件，下次加载自动回落到默认常量

**关键代码**：

```python
"""P8 业务规则提示词：加载 / 修改 / 恢复默认。

默认版内嵌为常量（source of truth）；
用户自定义版写到 overrides/ 目录；
加载优先级：overrides > 默认常量。
"""
import os
from pathlib import Path

# === 默认版（出厂；Git 跟踪；不依赖任何 .md 文件）=======================
P8_RULES_DEFAULT = """\
# P8 人机协同处置 业务规则

## 1. 风险叠加判定
当 P7 在同一作业 (job_id) 内输出多个 risk_event 时，按以下规则判定是否合并到同一 P8_job：
- 时间窗 ≤ 30 min 且同区域/同设备/同班组 → 必须合并
- 时间窗 ≤ 2 h 且风险描述指向同一根因 → 建议合并
- 时间窗 > 2 h 或无关联 → 不合并，各为独立 P8_job

合并后 max_level = 各事件 level 的 max；risk_basis 拼接所有事件的依据。
""".strip()  # ← 此处仅展示前 4 行；完整内容见主设计文档 § 5.3 / 仓库 git 历史

# === 路径常量 ===========================================================
PROMPT_DIR = Path(__file__).resolve().parent
OVERRIDES_DIR = PROMPT_DIR / "overrides"
DEFAULT_FILE_NAME = "P8_RULES.user.md"


def _override_path() -> Path:
    """override 文件路径：A7/prompt/overrides/P8_RULES.user.md"""
    return OVERRIDES_DIR / DEFAULT_FILE_NAME


# === 公开 API ============================================================

def load_rules() -> str:
    """加载当前生效的业务规则提示词。
    
    加载优先级：
        1. A7/prompt/overrides/P8_RULES.user.md  （用户自定义）
        2. P8_RULES_DEFAULT 常量                 （出厂默认）
    
    Returns:
        markdown 文本；trim 后的字符串
    """
    path = _override_path()
    if path.exists():
        return path.read_text(encoding="utf-8").strip()
    return P8_RULES_DEFAULT


def save_rules(content: str, *, ensure_ascii: bool = True) -> bool:
    """保存业务规则提示词到 override 文件。
    
    Args:
        content: 业务人员编辑后的完整 markdown 文本（覆盖式，不是增量）
        ensure_ascii: 写文件时是否使用 ensure_ascii（默认 True，跨平台兼容）
    
    Returns:
        True 成功；False 失败（异常被捕获并返回 False）
    
    Side effects:
        - 创建 A7/prompt/overrides/ 目录（如不存在）
        - 写入 A7/prompt/overrides/P8_RULES.user.md
        - 不修改 P8_RULES_DEFAULT 常量
    """
    try:
        OVERRIDES_DIR.mkdir(parents=True, exist_ok=True)
        path = _override_path()
        path.write_text(content, encoding="utf-8")
        return True
    except Exception:
        return False


def reset_rules() -> bool:
    """恢复默认：删除 override 文件，下次 load_rules() 自动回落到 P8_RULES_DEFAULT。
    
    Returns:
        True 成功（无论文件原本是否存在）；False 失败
    """
    try:
        path = _override_path()
        if path.exists():
            path.unlink()
        return True
    except Exception:
        return False


def get_default_rules() -> str:
    """返回出厂默认版常量（只读，不修改文件）。"""
    return P8_RULES_DEFAULT


def is_overridden() -> bool:
    """判断当前是否使用用户自定义版（override 文件是否存在）。"""
    return _override_path().exists()


# === 兼容旧名（与既有 P* 的 load_system_prompt 风格对齐；可选用）========
def load_rules_prompt(stage: str = "P8") -> str:
    """[DEPRECATED] 加载指定阶段的业务规则提示词。
    
    与 agents/utils/system_prompt.py 的 load_system_prompt() 风格对称；
    新代码请直接用 load_rules()，本函数仅作过渡期别名保留。
    """
    if stage != "P8":
        return ""
    return load_rules()
```

### 3.3 与 `agents/utils/system_prompt.py` 的边界

| 文件 | 加载内容 | 默认版来源 | 修改后行为 | 恢复默认 |
|------|---------|-----------|-----------|---------|
| `agents/utils/system_prompt.py` | `agents/system_prompt/{STAGE}_SYSTEM_PROMPT.md` | **磁盘 .md**（Git 跟踪） | 直接覆盖原 .md（**不可恢复**） | 从 Git 还原 |
| **`A7/prompt/p8_prompt.py`** | 业务规则（叠加 / 责任 / 通道） | **.py 内嵌常量** | 写 `overrides/*.user.md`（默认版不动） | `reset_rules()` 删 override |

**核心区别**：

- 系统提示词（开发侧）— 改动少、跟代码版本 → 直接覆盖 `.md`，出问题靠 Git 回滚
- 业务规则（业务侧）— 改动频繁、不能依赖 Git → 必须有"非破坏性"的用户自定义层

## 5. `A7/storage/` — 长期记忆后端

### 5.1 `A7/storage/p8_long_term.py`

**职责**：长期记忆存储抽象与默认实现。预留未来 SQLite / Redis 扩展。

**关键接口**：

```python
from abc import ABC, abstractmethod
from typing import Iterator
from A7.schema.p8_models import P8Job

class LongTermBackend(ABC):
    """长期记忆后端抽象。"""
    
    @abstractmethod
    def save(self, p8_job_id: str, archived_job: dict) -> None: ...
    
    @abstractmethod
    def get(self, p8_job_id: str) -> dict | None: ...
    
    @abstractmethod
    def search(self, query: str, limit: int = 20) -> list[dict]: ...
    
    @abstractmethod
    def load_all(self) -> Iterator[dict]: ...


class MockBackend(LongTermBackend):
    """模块级 dict 实现（与 P2/P4 既有约定一致）。"""
    
    def __init__(self):
        self._store: dict[str, dict] = {}
    
    def save(self, p8_job_id, archived_job):
        self._store[p8_job_id] = archived_job
    
    def get(self, p8_job_id):
        return self._store.get(p8_job_id)
    
    def search(self, query, limit=20):
        # 简单子串匹配：query 命中 risk_basis / note / a6_event_ids 任一字段
        results = []
        for job in self._store.values():
            searchable = " ".join([
                job.get("risk_basis", ""),
                job.get("note", ""),
                " ".join(job.get("a6_event_ids", [])),
                job.get("p8_job_id", ""),
            ])
            if query.lower() in searchable.lower():
                results.append(job)
                if len(results) >= limit:
                    break
        return results
    
    def load_all(self):
        return iter(self._store.values())


# 模块级单例
_backend: LongTermBackend | None = None

def get_long_term_backend() -> LongTermBackend:
    global _backend
    if _backend is None:
        _backend = MockBackend()
    return _backend

def reset_long_term_backend(backend: LongTermBackend | None = None) -> None:
    """测试 / 重启时重置后端。"""
    global _backend
    _backend = backend
```

## 6. `A7/runtime/` — 运行时服务

### 6.1 `A7/runtime/p8_poll_worker.py`

**职责**：单作业的后台轮询线程。扫描 `data/jobs/{job_id}/p7_result.json` 增量写入 LangGraph state。

**关键类**：

```python
import threading
import time
import logging
from pathlib import Path
from langchain_core.messages import HumanMessage

logger = logging.getLogger(__name__)


class P8PollWorker:
    """单 job_id 的后台轮询 worker。
    
    由 P8RuntimeService 启停；不直接对外暴露。
    """
    
    def __init__(self, job_id: str, agent, config: dict, interval_sec: int = 30):
        self.job_id = job_id
        self.agent = agent
        self.config = config
        self.interval_sec = interval_sec
        self._stop_event = threading.Event()
        self._thread: threading.Thread | None = None
        self._seen_event_ids: set[str] = set()
        self._p7_path = Path(f"data/jobs/{job_id}/p7_result.json")
    
    def start(self):
        if self._thread and self._thread.is_alive():
            logger.warning(f"[p8-poll] worker for {self.job_id} already running")
            return
        self._stop_event.clear()
        self._thread = threading.Thread(target=self._run, name=f"p8-poll-{self.job_id}", daemon=True)
        self._thread.start()
        logger.info(f"[p8-poll] worker for {self.job_id} started (interval={self.interval_sec}s)")
    
    def stop(self, timeout: float = 5.0):
        self._stop_event.set()
        if self._thread:
            self._thread.join(timeout=timeout)
            logger.info(f"[p8-poll] worker for {self.job_id} stopped")
    
    def _run(self):
        while not self._stop_event.is_set():
            time.sleep(self.interval_sec)
            if self._stop_event.is_set():
                break
            try:
                self._scan_once()
            except Exception as e:
                logger.exception(f"[p8-poll] {self.job_id} scan error: {e}")
    
    def _scan_once(self):
        if not self._p7_path.exists():
            return
        import json
        events = json.loads(self._p7_path.read_text()).get("risk_events", [])
        new_events = [e for e in events if e.get("a6_event_id") and e["a6_event_id"] not in self._seen_event_ids]
        if not new_events:
            return
        self._seen_event_ids.update(e["a6_event_id"] for e in new_events)
        msg = HumanMessage(content=(
            f"【P7 增量】检测到 {len(new_events)} 个新 risk_event：\n"
            + "\n".join(f"- {e['a6_event_id']} ({e.get('level', 'N/A')})" for e in new_events)
        ))
        logger.info(f"[p8-poll] {self.job_id} injecting {len(new_events)} new events")
        self.agent.invoke({"messages": [msg]}, config=self.config)
```

```python
import yaml
from pathlib import Path
from .p8_poll_worker import P8PollWorker


class P8RuntimeService:
    """P8 运行时服务：管理所有 job_id 的后台 worker。"""
    
    def __init__(self, config_path: str = "A7/runtime/p8_runtime.yaml"):
        self.config = self._load_config(config_path)
        self._workers: dict[str, P8PollWorker] = {}
    
    def _load_config(self, path: str) -> dict:
        p = Path(path)
        if not p.exists():
            return {"poll_interval_sec": 30, "max_idle_sec": 86400}
        return yaml.safe_load(p.read_text())
    
    def start(self, job_id: str, agent, config: dict) -> None:
        """启动 job_id 的后台轮询 worker（幂等）。"""
        if job_id in self._workers:
            logger.warning(f"[p8-runtime] worker for {job_id} already started")
            return
        worker = P8PollWorker(
            job_id=job_id,
            agent=agent,
            config=config,
            interval_sec=self.config.get("poll_interval_sec", 30),
        )
        worker.start()
        self._workers[job_id] = worker
    
    def stop(self, job_id: str) -> None:
        """停止 job_id 的后台轮询 worker。"""
        worker = self._workers.pop(job_id, None)
        if worker:
            worker.stop()
    
    def stop_all(self) -> None:
        """优雅关闭所有 worker。"""
        for job_id in list(self._workers.keys()):
            self.stop(job_id)


_service: P8RuntimeService | None = None

def get_runtime_service() -> P8RuntimeService:
    global _service
    if _service is None:
        _service = P8RuntimeService()
    return _service

def reset_runtime_service() -> None:
    """测试 / 重启时重置服务。"""
    global _service
    if _service:
        _service.stop_all()
    _service = None
```

def summarize_p8_job(job: dict) -> str:
    """从 P8_job 字段自动汇总 summary（归档时写入长期记忆）。
    
    Args:
        job: 工作记忆中的 P8_job dict
    
    Returns:
        简短摘要字符串，如：
        "max_level=HIGH | decision=approve | by=frontend:zhang | aggregated 3 events"
    """
    parts = [
        f"max_level={job.get('max_level')}",
        f"decision={job.get('decision') or 'N/A'}",
        f"by={_extract_decider(job.get('note', ''))}",
    ]
    if job.get("a6_event_ids") and len(job["a6_event_ids"]) > 1:
        parts.append(f"aggregated {len(job['a6_event_ids'])} events")
    return " | ".join(parts)


def _extract_decider(note: str) -> str:
    """从 note 字段提取决策者（约定格式："by {user_id}"）。"""
    if "by " in note:
        return note.split("by ")[-1].strip()
    return "system"

## 14. 关键决策回顾

| 决策 | 选择 | 理由 |
|------|------|------|

| 系统提示词留 agents/ | `agents/system_prompt/P8_SYSTEM_PROMPT.md` | 面向开发，与代码同位置便于对照 |
| 业务规则放 A7/prompt/ | `A7/prompt/p8_prompt.py`（默认常量）+ `overrides/P8_RULES.user.md`（运行时覆盖） | 面向业务，非破坏性修改 + 一键恢复 |
