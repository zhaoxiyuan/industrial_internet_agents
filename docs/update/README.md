# 每日更新记录

本目录统一存放项目的每日更新记录。

## 命名规则

- 文件名格式：`update_YYYY-MM-DD.md`
- 每个自然日使用一份更新记录。
- 同一天的后续修改追加到当天文件，不在 `docs` 根目录重复新建。
