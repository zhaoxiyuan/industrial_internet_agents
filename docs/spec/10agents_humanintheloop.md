| 阶段 | 业务人员正在做什么 | 智能体需要提供什么帮助 | 主要人工确认 |
|------|------------------|----------------------|-------------|
| P1 作业预约与准备 | 提交作业内容、时间、区域和人员 | 识别作业类型，提示JSA和措施缺项 | 作业申请确认 |
| P2 建立作业任务 | 将一项作业纳入智能协同管理 | 建立唯一任务编号和初始状态 | 是否纳入监测 |
| P3 理解作业上下文 | 核对作业对象、人员、设备和风险 | 形成统一作业信息包 | 信息缺失确认 |
| P4 关联现场资源 | 确认摄像头、移动终端和检测资源 | 推荐可用监测资源 | 资源绑定确认 |
| P5 作业前核验 | 检查人员、PPE、隔离、气体和消防措施 | 形身逐项检查结果和证据 | 允许开工或退回整改 |
| P6 过程动态监测 | 现场正常开展作业 | 持续发现行为和环境变化 | 一般不需持续操作 |
| P7 风险研判 | 判断是否构成真实风险 | 融合作业背景、视频和规则进行判级 | 高风险事件确认 |
| P8 人机协同处置 | 组织整改、暂停或升级 | 找到责任岗位并推送处置要求 | 下发、暂停、恢复 |
| P9 闭环跟踪 | 整改、反馈、复核和关闭 | 催办、检查证据和关闭条件 | 事件和作业关闭 |
| P10 报告复盘 | 查阅全过程并分析高频问题 | 自动生成报告、汇总项目资料和优化建议 | 报告确认 |
