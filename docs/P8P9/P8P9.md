## 7 个状态（job_status）

```
open → acknowledged → rectifying → materials_in_audit → waiting_human_review → ready_to_close → closed
```

| 状态 | 含义 | 主要业务 |
|---|---|---|
| `open` | 待接取 | acknowledge_disposition |
| `acknowledged` | 已接取 | submit_rectification_materials / relinquish_job |
| `rectifying` | 整改中（驳回后） | submit_rectification_materials（重交） |
| `materials_in_audit` | P9 审核中 | record_closure_review（人工终审） |
| `waiting_human_review` | 等待人工终审 | record_closure_review / escalate / downgrade |
| `ready_to_close` | 待终审关闭 | record_closure_review（approved → closed） |
| `closed` | 已关闭（已归档） | archive_job_to_long_term_memory |

## 7 个业务动作

| 函数 | 状态变化 | 触发卡片更新 |
|---|---|---|
| `acknowledge_disposition` | open → acknowledged | ✓ |
| `submit_rectification_materials` | acknowledged/rectifying/waiting_human_review → materials_in_audit（两阶段 transition） | ✓ + 触发 P9 audit |
| `relinquish_job` | acknowledged/rectifying → open（清 materials） | ✓ |
| `escalate_risk` | （不变 status）写 risk_changes + 改 event.risk_level | ✓ |
| `downgrade_risk` | （不变 status）写 risk_changes[pending_review] → mock P9 通过 → applied | ✓ |
| `record_closure_review` | waiting_human_review / ready_to_close / materials_in_audit → closed（approved）/ rectifying（rejected） | ✓ + archive |
| `archive_job_to_long_term_memory` | （不变 status）写 _long_term/{job_id}.json | × |

## 3 个 service

1. **ClosureService**（state_machine.py）：状态机 + 原子写 + 乐观锁
2. **ClosureLinkService**（links.py）：attachment link（下载用）+ upload token（上传用）
3. **UploadService**（upload_service.py）：附件二进制存储 + 校验

## 3 个 agent 白名单接口

`agent_interface.py` 暴露 3 个方法（仅 agent 可调用）：
- `initialize_job_for_agent(job_id, *, actor, events)` 
- `bind_card_for_agent(job_id, *, actor, binding)` 
- `get_state_for_agent(job_id)`

## 附件上传（2026-09-20 方案 B）

详见 [P8_UPLOAD.md](./P8_UPLOAD.md)。

**TL;DR**：
- 飞书 Card 2.0 无原生文件上传 → 走"短时 token + 独立上传页"
- 文件存 `{base_dir}/{job_id}/uploads/{upload_id}.bin`
- metadata 存 `state.upload_links[token].uploads[]` + 业务字段 `materials.submissions[].uploads[]` / `risk_changes[].uploads[]`
- 4 个业务动作加 `upload_token` 可选参数
