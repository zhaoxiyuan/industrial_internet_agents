# Changelog

## 0.1.0 — 2026-08-10

- Initial standalone channel-gateway extraction/reimplementation.
- REST, Webhook, SSE, Agent callback, persistent single-instance JSON queue.
- Loopback, Generic HTTP, and Feishu/Lark adapters.
- Inbound dedupe, per-session callback ordering, retry, dead-letter handling.
- Outbound intents, idempotency, receipts, and unknown-send protection.
- Chinese API, architecture, security, deployment, adapter, and LangGraph documentation.
