# A6 前端功能需求说明文档

> **文档版本**: v0.2
> **编制日期**: 2026-08-10
> **对应模块**: A6 风险研判智能体 - 前端界面
> **核心定位**: A6 对 A5 上报的告警事件进行**聚合**和**风险打分**

---

## 一、需求概述

### 1.1 A6 核心职责

```
A5 检测到违规事件 → A6 接收 → 事件聚合 + 风险打分 → 输出给 A7
```

- **事件聚合**: 将时间上接近、同一人、同一类型的告警合并为一个事件
- **风险打分**: 基于可编辑的提示词，使用 LLM 判断风险等级

### 1.2 与 A5 的关系

A6 前端**复用 A5 的基础组件**，只在 A5 基础上叠加 A6 特有的功能：

| 功能 | A5 | A6 |
|------|----|----|
| 多 Tab 结构 | ✅ | ✅ 已开发 |
| 实时数据展示 | ✅ | ✅ 已开发 |
| 作业票规则编辑 | ✅ | ❌ A6 不需要 |
| **风险分级提示词编辑** | ❌ | ✅ **新增** |
| **事件聚合展示** | ❌ | ✅ **新增** |
| **多事件时间视角研判** | ❌ | ✅ **新增** |

## 四、核心功能点

### 4.1 自定义风险分级提示词

**功能说明**：
- A6 使用可编辑的提示词（`prompts.py`）进行风险分级
- 前端提供提示词的**读取、编辑、保存**功能
- 修改后实时生效，下次研判使用新提示词

**UI 设计**：
```
┌─ 风险分级提示词 ──────────────────────────────────────────────────┐
│  [保存] [重置为默认]                                               │
│                                                                     │
│  <textarea>                                                        │
│  你是一个作业安全风险分析专家。你的职责是对告警事件进行风险等级研判。  │
│                                                                     │
│  ## 风险等级定义（5级）                                            │
│  | 等级 | 名称 | 含义 | ...                                        │
│  ...                                                               │
│  </textarea>                                                       │
└─────────────────────────────────────────────────────────────────┘
```

**交互流程**：
1. 页面加载时读取 `prompts.py` 中的 `RISK_CLASSIFICATION_SYSTEM_PROMPT`
2. 用户编辑后点击"保存" → 调用 `PromptManager.save_to_file()`
3. 下次 A6 Agent 研判时自动使用新提示词

### 4.2 显示完整事件（时间范围 + 事件描述）

**功能说明**：
- 每条研判结果展示完整的时间范围（`first_seen` ~ `last_seen`）
- 展示事件类型、涉及人员、证据摘要

**UI 设计**：

```
│  涉及人员:     P11(李师傅)                                          │
│  时间范围:     2026-08-06 15:43:05 ~ 15:43:15  (持续10秒)           │
│                                                                   │
│  ── 来源事件 ──                                                    │
│  • A5-P11-1722933125: 15:43:05 首次发现                            │
│    证据: 护目镜缺失率100%, 位于动火区-A                             │
│                                                                   │
│  ── 风险分级 ──                                                    │
│  风险等级:   较重(3)                                               │
│  等级依据:   基础等级2 + 危险区+1 = 3                               │

└───────────────────────────────────────────────────────────────────┘
```

### 4.3 时间视角风险研判（多事件聚合）

**功能说明**：
- 按**时间段**聚合展示研判结果（而非按单个事件）
- 展示某个时间窗口内的整体风险状况
- 支持查看时间窗口内的所有聚合事件

**UI 设计**：
```
┌─ 研判看板 ──────────────────────────────────────────────────────┐
│  时间范围: [15:43:00 ▼] ~ [15:44:00 ▼]  [刷新]                   │
│                                                                   │
│  ┌─ 时间窗口风险概览 ─────────────────────────────────────────┐   │
│  │ 15:43:00 - 15:44:00  内共发生 3 个事件，整体风险: 较重(3)     │   │
│  │                                                           │   │
│  │ 风险趋势: ████████░░░░░░░░░░░░░░░░░  较重                  │   │
│  └───────────────────────────────────────────────────────────┘   │
│                                                                   │
│  ┌─ 聚合事件列表 ─────────────────────────────────────────────┐   │
│  │ 时间窗口           事件类型         人员     风险    操作    │   │
│  │ 15:43:05-15:43:15  PPE缺失-护目镜   P11      较重    [查看] │   │
│  │ 15:43:10-15:43:25  PPE缺失-头盔     P7       危急    [查看] │   │
│  │ 15:43:15-15:43:30  PPE缺失-防护服   P8       一般    [查看] │   │
│  └───────────────────────────────────────────────────────────┘   │
│                                                                   │
│  ┌─ 事件详情 ─────────────────────────────────────────────────┐   │
│  │ (点击列表项后展开详情)                                       │   │
│  └───────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

**时间窗口聚合逻辑**（后端实现）：
```
1. A6 读取 A5 上报的多个 raw_event 文件
2. 按时间窗口（如 5 分钟）聚合
3. 同一人员的同类违规断续发生 → 聚合为同一事件
4. 聚合后的事件计算整体风险等级
5. 输出给前端展示
```

## 五、后端接口设计

### 5.1 新增接口

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/a6/assessments` | GET | 获取研判结果列表（支持时间范围筛选） |
| `/api/a6/assessments/{id}` | GET | 获取单条研判详情 |
| `/api/a6/status` | GET | 获取 A6 状态和 event_id_map |
| `/api/a6/prompts` | GET | 获取所有提示词 |
| `/api/a6/prompts/{name}` | GET | 获取指定提示词内容 |
| `/api/a6/prompts/{name}` | POST | 更新提示词（仅内存） |
| `/api/a6/prompts/{name}/save` | POST | 保存提示词到文件 |
| `/api/a6/prompts/{name}/reset` | POST | 重置为默认 |

### 5.2 接口响应格式

**GET /api/a6/assessments?start=15:43:00&end=15:44:00**
```json
{
  "time_window": {
    "start": "2026-08-06T15:43:00",
    "end": "2026-08-06T15:44:00"
  },
  "summary": {
    "total_events": 3,
    "overall_risk_level": 3,
    "overall_risk_name": "较重"
  },
  "items": [
    {
      "a6_event_id": "A6-20260806-165028-529",
      "event_type": "PPE缺失-护目镜",
      "first_seen": "2026-08-06T15:43:05",
      "last_seen": "2026-08-06T15:43:15",
      "duration_sec": 10.0,
      "involved_persons": ["P11"],
      "risk_level": 3,
      "risk_level_name": "较重"
    }

}
```

**GET /api/a6/prompts/risk_classification**
```json
{
  "name": "risk_classification",
  "content": "你是一个作业安全风险分析专家...",
  "last_modified": "2026-08-06T16:00:00"

```

**POST /api/a6/prompts/risk_classification/save**

## 七、与 A5 前端的关系

A6 前端**独立部署**：

1. **A5 前端**已有完整的 Tab 结构（实时数据、Agent进度、作业票规则、系统提示词）
2. **A6 研判看板**作为独立页面运行（`index_a6.html`）

**启动方式**：
```bash
python frontend/app_a6.py
# 访问 http://localhost:5001
```
