📡 飞书交互闭环

本服务(端口 8080)是飞书卡片按钮回调的入口。飞书用户点击按钮 → Node.js Gateway 转发到本服务 → 转发到 P8P9 状态机。

P8P9 Web 面板 (8089) P8 详情模板

🔌 配套服务入口

本服务只覆盖 P6-P9 业务辅助 endpoint,以下服务由各自的"自带前端"提供:

P6 监测 + A5/A6 (5002) P8P9 状态机 Web (8089) 配置前端 (5000) 飞书配置 UI (5003) Gateway 健康检查

📋 本服务暴露的 API

  • POST /api/feishu/card-callback — 飞书卡片按钮回调入口(转发到 P8P9)
  • GET /api/jobs/{job_id}/working-memory — P8 工作记忆快照查询
  • GET /api/feishu/card-callbacks — 已注册飞书卡片 ID 索引

说明: 本服务刻意不服务 /api/config、/api/prompt/{stage}、/api/workflow/* 等 endpoint, 因为这些是 P1-P5 主流程相关,不在 a/ 子项目范围内。完整 P1-P10 Web 服务请用根目录 web/server.py(端口 8080,会跟本服务冲突,只能二选一)。

⚠️ 与根目录 webui 的差异

根目录原版 web/server.py 是 P1-P10 编排入口,依赖 agents.main_agent(P1-P5 全套);

a/ 子项目只服务 P6-P9,所以本服务是精简版,仅保留 飞书卡片回调 + P8 工作记忆查询 + 卡片索引 三个 endpoint。

完整 P1-P10 编排请用根目录原版,或重新启动 python aaaseverstart.py start webui。
