协作使用方式
在会话中向主 Agent 用自然语言提出需求。主 Agent 根据被调用 Agent 的契约整理参数，信息不足时向用户追问，再通过授权 Tool 分派子任务。
本页管理协作授权，并查看统一任务表、执行状态和成果。

命令执行
python cli.py catalog 查看目录；catalog --agent ID 查看该 Agent 获授权命令。Runtime 使用一次性票据调用。业务凭据由后端注入，命令返回结构化 JSON。
