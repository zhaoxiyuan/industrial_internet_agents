# 拓扑右侧心跳管理

选中 Agent 节点，右侧展示全部心跳计划的状态、周期、描述、防重入范围、超时、下次触发时间及作业票。

添加默认不启用；可配置周期、单轮超时、首次触发、任务描述、JSON 输入、防重入范围、共享键。业务 Agent 须先绑定作业票。弹窗不受每 4 秒自动刷新影响。

配置使用当前 version，冲突时重新打开配置。暂停和恢复仅影响未来触发。已关闭作业票不能恢复旧计划。

删除使用管理员 DELETE /api/schedules/{id}，请求体为当前 version。事务内检查版本并移除计划，保留任务及触发历史，不取消在途任务；Agent 工具仍只提供暂停/恢复/停止。

Main 推荐仅当前 Agent 防重入，每轮独立对话，忙时跳过且不补发。整条任务链模式同时等待子任务。
