# 原始事件播放器

播放器保存CV、传感器、定位、PPE及人员/设备/区域关联表，正常播放时逐秒写入事实。当前业务流程通过只读时间窗口接口访问，不让播放器承担P6/P7业务调度。

GET /v4/data/windows支持window_seconds、可选start_time/end_time、after和limit。GET /v2/data/window按精确起止时间读完整关联快照。旧/v2/tasks接口仅供旧客户端兼容，不被当前Main/P6 Skill调用。

Mac公网/player/；宿主端口18090。单独开发默认端口5010，不可混作生产映射。POST /v2/player/start播放场景，/stop停止，/status读状态。播放结束不代表作业结束。

当前契约：单作业票、时间调度（v4）。Main 管票与时间进度，P6 每次读取一个原始窗口并原子保存一份 P6_P7 描述；P7 顺序研判；P8/P9 维护同一卡片并复核材料。播放器只作为原始关联事件数据源，新流程不调用播放器任务领取/完成接口。窗口 ID、租约、精确时间和幂等由工具内部维护。

## F：一小时连续作业

新增 F 场景，持续 3600 秒，实时 1×产生数据。包含多次 PPE 异常、气体/温度/火焰异常、监护人离岗；全程无缺测，全部异常在结束前恢复。A–E 仍为 30 秒。详细分钟表和甘特图见 [F 场景](docs/SCENARIO_F.md)。加载场景不会自动启动播放或 Agent。
