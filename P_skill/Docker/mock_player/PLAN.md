# 播放器与Agent边界

原始事件及关联信息由播放器维护，窗口是只读查询视图；P6占用和一次写入由业务SQLite维护。窗口列表按时间排序并分页，不预生成消费任务。

当前保留旧任务表及接口以兼容历史播放器客户端；新业务不依赖这些状态。清理历史后原始样本为空，人员/设备/场景定义保留。所有未来播放器改动必须保持只读列表不写业务状态、快照完整、时间时区明确。

当前契约：单作业票、时间调度（v4）。Main 管票与时间进度，P6 每次读取一个原始窗口并原子保存一份 P6_P7 描述；P7 顺序研判；P8/P9 维护同一卡片并复核材料。播放器只作为原始关联事件数据源，新流程不调用播放器任务领取/完成接口。窗口 ID、租约、精确时间和幂等由工具内部维护。
