# 清理历史数据（2026-10-15）

播放器工具栏“清理所有历史数据”调用 POST /v2/player/clear-history，请求体 {"confirm":"CLEAR_PLAYER_HISTORY"}。播放中、停止中或旧 processing 任务存在时拒绝；删除前创建数据库备份。保留人员、设备、区域配置，清理 CV、传感器、定位、PPE、旧处理任务及结果，重置进度；历史证据 ID 不复用。

当前 v4 流程从 /v4/data/windows 按时间读取原始数据，不再创建或领取播放器消费者任务。播放器不认识作业票；播放结束和清理都不自动关闭业务监测。

单独清理播放器不会清理平台任务、聊天、P6_P7 业务库或卡片引用。全流程重跑必须协调清理，不能把残留业务引用当作新一轮数据。本次已按用户授权先备份，再清理当前 Mac 平台、共享业务库和播放器，然后正常播放 B 场景并真实调用 Agent。当前验收证据与备份位置见 [真实验收](../../../LIVE_PLATFORM_ACCEPTANCE.md)。备份保留，不参与当前队列。
