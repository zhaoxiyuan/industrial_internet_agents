# 前端摘要与工具详情按需加载

2026-10-14。详细工程工具描述是模型调用契约，不应在打开平台首页时全部发送。模型工具目录由后端Agents.catalog/build_tools按绑定及授权生成，与前端是否展开详情无关。

## 当前接口

| 接口 | 返回内容／加载时机 |
|---|---|
| GET /api/overview | Skill/提供者摘要、工具名称与数量、Agent状态、协作关系、会话及近期任务摘要；details_deferred=true |
| GET /api/skills/<id> | 点击查看Skill内容时加载正文、资源列表与完整声明 |
| GET /api/tool-providers/<id> | 查看或配置该来源时读取完整工具描述和Schema；来源ID含skill:/http:/cli:/mcp:前缀 |
| GET /api/cli/catalog | 查看平台工具详情时读取内置、协作和成果工具说明与Schema |
| GET /api/cli/catalog?agent_id=<id> | 管理员核对模型侧当前有效授权目录，不依赖前端概览；不执行工具 |
| GET /api/tasks/<id> | 点击任务详情读取完整公开执行结果；不返回私有模型检查点 |
| GET /api/operations/<id>、/api/tool-runs/<id> | 展开后台操作或调用回执时读取完整结果 |

概览中的Skill无body/files或完整工具Schema；提供者只保留名称与可用性。任务概览保留ID、关系、状态、阶段、错误、时间与成果索引，完整result/input等在详情接口读取；操作和工具回执也不重复携带result。后端存储未删减。HTTP定义编辑时按需获取完整Schema并使用原provider_id保存，不能把带类型前缀的展示ID作为底层注册ID。

## 缓存及边界

前端按来源ID+revision缓存详情。换来源时不展示旧请求结果，目录修订后读取新详情。只有点击查看正文/工具说明/回执才请求详情；绑定复选框可先按名称选择，不需下载全目录。完整模型描述/参数仍由后端直接读取，与这些前端缓存无关。详情接口沿用原管理员同源校验，不授予模型额外权限；Skill读取和业务执行仍经过各自授权门。

原前端20秒概览超时不足以承载约600KB响应经当前隧道传输；本次概览改为摘要，同时概览请求容忍60秒网络等待，其他普通请求仍20秒。延长等待不是执行超时，也不能替代按需加载。

## 验证

同一现有平台后端响应由全量约567KB降为摘要约149KB。测试证明大正文、工程工具说明、参数Schema和执行结果不随概览传输，但详情读取无损；模型有效目录仍保留WORK_PERMIT_ID_MISMATCH等实际工程契约。历史回执和当前业务事实未改写。独立证据见.runtime/evidence/overview-compact-acceptance.json。
